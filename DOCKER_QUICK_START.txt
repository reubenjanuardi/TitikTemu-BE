## 🚀 To Get Started

### 1. Setup Environment (1 minute)
```bash
cp .env.docker .env
# Edit .env with your values (especially JWT_SECRET)
```

### 2. Build All Services (2-5 minutes)
```bash
docker-compose build
```

### 3. Start Everything (10 seconds)
```bash
docker-compose up -d
```

### 4. Verify it Works (30 seconds)
```bash
# Check status
docker-compose ps

# Test gateway
curl http://localhost:3000

# View logs
docker-compose logs -f
```

**That's it! You're running containerized microservices! 🎉**

## 🔧 Common Commands

```bash
# Start services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop services
docker-compose down

# Check status
docker-compose ps

# Access database
docker-compose exec postgres psql -U titiktemu -d titiktemu_db

# View service logs
docker-compose logs auth-service

# Rebuild after code changes
docker-compose build auth-service
docker-compose up -d auth-service
```
